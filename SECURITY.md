# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please report vulnerabilities through GitHub Private Vulnerability
Reporting:

https://github.com/jojusa/relinkra/security/advisories/new

Do not open a public issue for a security problem.

## Scope

The following classes of issues are in scope for Relinkra:

- Writes escaping the intended workspace or host-config target.
- Exposure of credentials or secret material.
- Execution of untrusted or unverified backend binaries.
- Bypass of provenance or checksum verification.
- Evidence false-greens that affect release safety.
